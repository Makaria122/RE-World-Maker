# Changelog

All notable changes to RE World Maker are documented here.

## [0.1.0] - 2026-09-16

Initial preview release.

### Added

- REW Interact, Player, Pickup Use, and World Start triggers.
- REW Prop Toggle, Audio, Animator Parameter, and Teleport actions.
- Global synchronization for Prop Toggle and Audio actions with late-join support.
- Automatic separation between VRC Object Sync and manually synchronized REW state.
- Easy Settings mode for beginner-friendly inspectors.
- Japanese, English, Korean, and Simplified Chinese inspector help.
